# Support

SSD Watcher is a small, community-supported open-source project. There is no
paid support channel or guaranteed response time, but clear reports are
welcome.

## Before opening an issue

1. Install the latest released version.
2. Use **Settings → Scan for agent data now**.
3. Confirm the database belongs to Codex, OpenClaw, or Hermes.
4. Search existing issues for the same symptom.

Use the repository's issue forms for bugs, feature ideas, or support for a new
database layout. Include the SSD Watcher version, macOS version, installation
method, and concise reproduction steps.

Never upload a database, prompt history, authentication file, API key, or
credential. Paths and screenshots should be reviewed for usernames or other
private information before posting.

Security vulnerabilities and privacy failures belong in the private channel
described in [SECURITY.md](SECURITY.md), not in a public issue.
