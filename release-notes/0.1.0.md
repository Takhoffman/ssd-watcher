# SSD Watcher 0.1.0

- Automatically discovers default, renamed, nested, active, and external-drive
  Codex homes using multiple independent signals.
- Measures SQLite insert and byte-growth rates without reading prompt or
  response content.
- Alerts only when sustained writes exceed intentionally conservative
  thresholds.
- Includes a polished menu-bar dashboard, notification support, launch at
  login, manual location selection, and secure in-app updates.
