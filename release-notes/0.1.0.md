# SSD Watcher 0.1.0

- Automatically discovers Codex, OpenClaw, and Hermes data stores, including
  multiple homes, named profiles, renamed folders, live processes, and
  external drives.
- Verifies each store by its SQLite schema instead of trusting a folder or
  filename.
- Samples record and byte-growth rates every 10 seconds and rediscovers new
  locations every five minutes without reading prompt or response content.
- Alerts only when sustained writes exceed intentionally conservative
  thresholds.
- Includes a polished menu-bar dashboard, notification support, launch at
  login, manual location selection, and secure in-app updates.
- Ships as a universal, Developer ID signed and Apple-notarized Mac app with
  Sparkle updates and a Homebrew Cask.
